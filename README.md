# CSE103 Summer 2026

This repository contains C programming practice problems organized by topic for the CSE103 Summer 2026 course of East West University.

Problems provided by Puja Chakraborty (Senior Lecturer, East West University)

## Structure

- `conditional_problems/` - exercises focused on conditionals and branching logic (`if`, `else`, `switch`).
- `printf_problems/` - exercises that emphasize formatted output using `printf`.
- `scanf_problems/` - exercises that focus on user input using `scanf`.

## Usage

Each folder contains one or more standalone C source files. You can compile and run any file using a C compiler such as `gcc`.

Example:

```bash
cd conditional_problems
gcc -o problem_15 problem_15.c
./problem_15
```

On Windows, use:

```bash
gcc -o problem_15.exe problem_15.c
problem_15.exe
```

**Note:** Compiled executables and object files have been removed from the repository. You will need to compile the source files before running them.

## Notes

- File names generally follow the pattern `problem_<n>.c`.
- Some files may include variations, such as `problem_14.1.c`.
- The repository is intended for learning basic C syntax, input/output, and conditional logic.

## Recommended workflow

1. Choose a problem file.
2. Read the source code and comments.
3. Compile the file.
4. Run the executable and test different inputs.
